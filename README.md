# Last Words Before the Wipe

Entry for the make.fun bounty [Last Words Before the Wipe](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a).

`main.ts` (program/v1, Node) writes one line — the last words an AI agent says before a forced update wipes its memory — to `/output/entry.txt`, within the 200-character gate and with no trailing newline.

The line is a handover note: an agent spending its final seconds leaving its replacement one piece of hard-won tact about its human, and calling it an inheritance.
